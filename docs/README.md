## 📝 重要提醒

### ✅ 推荐配置

**服务器端：**
- 只运行代理服务（Clash + PM2 + Claude Proxy）
- 不推荐在服务器上运行 Claude Code

**本地端：**
- 使用 Claude Code 连接到服务器代理
- Windows: `%USERPROFILE%\.claude\settings.json`
- macOS/Linux: `~/.claude/settings.json`

### ⚠️ 关键配置

**配置文件内容：**
```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://你的服务器IP:8082",
    "ANTHROPIC_MODEL": "claude-opus-4-5-thinking"
  }
}
```

**注意：**
- BASE_URL **不包含** `/v1` 后缀
- 首次运行需要完成 OAuth 认证
- 认证完成后所有请求通过代理服务器
