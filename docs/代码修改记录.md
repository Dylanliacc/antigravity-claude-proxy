# 代码修改记录

> 记录所有为支持代理而做的代码修改

## 📅 修改日期
**日期**: 2026-01-05
**原因**: Node.js 原生 fetch API 不支持 HTTP_PROXY/HTTPS_PROXY 环境变量

---

## 🎯 修改目标

让 Node.js 应用能够通过 Clash 代理 (127.0.0.1:8083) 访问 Google API。

---

## 📦 新增依赖

### undici
**版本**: 最新稳定版
**安装命令**:
```bash
npm install undici
```

**用途**: 提供支持代理的 HTTP 客户端（ProxyAgent）

**为什么需要**:
- Node.js 18+ 内置的 fetch API 不支持 HTTP_PROXY 环境变量
- undici 提供了 ProxyAgent，可以配置代理
- 完全兼容 Fetch API 标准

---

const createProxyFetch = () => {

## 🔍 代码解析

### ProxyAgent 工作原理

```javascript
const createProxyFetch = () => {
  // 1️⃣ 从环境变量读取代理地址
  const proxyUrl = process.env.HTTPS_PROXY || process.env.HTTP_PROXY;

  if (proxyUrl) {
    // 2️⃣ 创建代理代理器
    const proxyAgent = new ProxyAgent(proxyUrl);

    // 3️⃣ 返回包装后的 fetch 函数
    return (url, options = {}) => undiciFetch(url, {
      ...options,
      dispatcher: proxyAgent  // 使用代理发送请求
    });
  }

  // 4️⃣ 如果没有代理，直接使用 undici fetch
  return undiciFetch;
};

// 5️⃣ 创建全局 fetch 实例
const fetch = createProxyFetch();
```

**请求流程**:
```
代码调用 fetch(url, options)
    ↓
createProxyFetch() 返回的包装函数
    ↓
检查是否设置了 HTTP_PROXY 环境变量
    ↓
有代理 → undiciFetch(url, { ...options, dispatcher: proxyAgent })
    ↓
ProxyAgent 将请求转发到 127.0.0.1:8083 (Clash)
    ↓
Clash 将请求转发到真实目标 (oauth2.googleapis.com)
```

## 📊 环境变量流向

```
PM2 ecosystem.config.cjs
  env: {
    HTTP_PROXY: 'http://127.0.0.1:8083',
    HTTPS_PROXY: 'http://127.0.0.1:8083'
  }
    ↓
PM2 启动 Node.js 进程
    ↓
process.env.HTTP_PROXY = 'http://127.0.0.1:8083'
process.env.HTTPS_PROXY = 'http://127.0.0.1:8083'
    ↓
createProxyFetch() 读取环境变量
    ↓
new ProxyAgent('http://127.0.0.1:8083')
    ↓
所有 fetch() 请求使用代理
```
