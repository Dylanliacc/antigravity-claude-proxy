## 🎯 按使用场景选择文档

### 场景1: 第一次部署 / 完整部署
1. 阅读 **[部署配置文档.md](./部署配置文档.md)** 的"服务器环境配置"章节
2. 按照"账号管理"章节添加账号
3. 按照"服务启动和管理"章节启动服务
4. 执行"测试和验证"中的所有测试

### 场景2: 每天启动服务
1. 使用 **[快速启动指南.md](./快速启动指南.md)** 的启动命令
2. 运行健康检查确认服务正常
3. 如有异常，查看 **[故障排查速查表.md](./故障排查速查表.md)**

### 场景3: 添加新账号
1. 查看 **[快速启动指南.md](./快速启动指南.md)** 的"账号管理"部分
2. 或查看 **[部署配置文档.md](./部署配置文档.md)** 的"账号管理"章节（更详细）

### 场景4: 服务出现异常
1. 先查看 **[故障排查速查表.md](./故障排查速查表.md)** 的错误分类表
2. 根据错误信息找到对应的排查步骤
3. 如果仍无法解决，查看 **[部署配置文档.md](./部署配置文档.md)** 的"故障排查"章节

### 场景5: 理解代码修改
1. 阅读 **[代码修改记录.md](./代码修改记录.md)**
2. 了解为什么需要 undici 和 ProxyAgent
3. 查看修改的具体文件和代码

### 场景6: 系统维护和监控
1. 查看 **[部署配置文档.md](./部署配置文档.md)** 的"维护和监控"章节
2. 使用 **[故障排查速查表.md](./故障排查速查表.md)** 的健康检查脚本
3. 定期执行备份和日志清理

### 场景7: 配置服务器端 Claude Code
1. 阅读 **[服务器Claude配置指南.md](./服务器Claude配置指南.md)** 完整配置步骤
2. 如有问题，查看 **[Claude配置完成总结.md](./Claude配置完成总结.md)** 了解常见错误
3. 参考 **[快速启动指南.md](./快速启动指南.md)** 的服务器端配置部分

### 场景8: Clash 代理问题
1. 查看 **[Clash代理管理指南.md](./Clash代理管理指南.md)**
2. 使用 `clash-control.sh` 脚本管理 Clash
3. 如仍有问题，查看 **[故障排查速查表.md](./故障排查速查表.md)**
