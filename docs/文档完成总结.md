## 📌 重要提醒

### 配置摘要

**服务器信息**:
- IP: YOUR_SERVER_IP
- SSH用户: ecs-user
- SSH密码: YOUR_SSH_PASSWORD

**端口配置**:
- Claude Proxy: 8082 (主服务)
- Clash HTTP: 8083 (代理)
- Clash Dashboard: 8084 (管理界面)

**启动命令**:
```bash
# 启动 Clash
sudo systemctl start mihomo

# 启动 Claude Proxy
cd ~/antigravity-claude-proxy
pm2 start ecosystem.config.cjs
```

**健康检查**:
```bash
# 测试服务
curl http://localhost:8082/health

# 查看账号
curl http://localhost:8082/account-limits

# 访问 Dashboard
http://YOUR_SERVER_IP:8084/ui/
```

## 🔧 核心修改说明

为了让服务器能够通过 Clash 代理访问 Google API，我修改了3个文件：

1. **src/oauth.js** - OAuth 认证模块
2. **src/account-manager.js** - 账号管理模块
3. **src/accounts-cli.js** - CLI 工具

**修改内容**: 在每个文件开头添加了 undici ProxyAgent 支持，使 fetch 请求能够通过 HTTP_PROXY 环境变量指定的代理。

**详细说明**: 查看 [代码修改记录.md](./代码修改记录.md)
