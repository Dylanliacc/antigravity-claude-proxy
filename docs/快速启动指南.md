## 🚀 5分钟快速启动

### 1. 连接服务器
```bash
ssh ecs-user@YOUR_SERVER_IP
# 密码: YOUR_SSH_PASSWORD
```

### 2. 启动服务
```bash
# 启动 Clash 代理（通常已经在运行）
~/clash-control.sh status  # 先检查状态
~/clash-control.sh start   # 如果未运行才启动

# 启动 Claude Proxy
cd ~/antigravity-claude-proxy
pm2 start ecosystem.config.cjs

# 查看状态
pm2 status
```

### 3. 验证服务
```bash
# 测试健康检查
curl http://localhost:8082/health

# 测试模型列表
curl http://localhost:8082/v1/models

# 查看账号状态
curl http://localhost:8082/account-limits
```

### 4. 本地使用（推荐）

**⚠️ 注意**：由于 Claude Code 首次运行强制要求 OAuth 认证（需要浏览器），不推荐在服务器上使用。建议在本地电脑使用。

**在本地电脑设置环境变量**：

```bash
# 方式1: 环境变量
export ANTHROPIC_BASE_URL=http://YOUR_SERVER_IP:8082/v1

# 方式2: 配置文件（推荐）
mkdir -p ~/.config/claude-code
cat > ~/.config/claude-code/settings.json << 'EOF'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://YOUR_SERVER_IP:8082/v1"
  }
}
EOF

# 使用 Claude Code
claude --model claude-sonnet-4-5-thinking "Hello"
```

✅ **完成！** 现在可以使用代理服务了。

### 5. 服务器端使用（不推荐）

<details>
<summary>点击展开服务器端配置（高级用户）</summary>

如果在服务器上也安装了 Claude Code，需要配置它使用本地代理：

```bash
# 创建配置目录
mkdir -p ~/.config/claude-code

# 创建配置文件
cat > ~/.config/claude-code/settings.json << 'EOF'
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:8082",
    "ANTHROPIC_API_KEY": "sk-ant-api03-proxy-local-dummy-key-for-testing-only"
  },
  "theme": "dark",
  "model": "sonnet"
}
EOF

# 配置环境变量
cat >> ~/.bashrc << 'EOF'

# Antigravity Claude Proxy 配置
export ANTHROPIC_BASE_URL=http://localhost:8082
export ANTHROPIC_API_KEY=sk-ant-api03-proxy-local-dummy-key-for-testing-only
EOF

source ~/.bashrc

# 首次运行仍需要完成 OAuth 认证（需要复制链接到本地浏览器）
claude 'hello'
```

**限制**：
- 首次运行强制要求 OAuth 认证
- 需要在本地浏览器完成认证流程
- 需要复制认证码回服务器
- 流程复杂，不推荐

详细说明请参考 [服务器Claude配置指南.md](./服务器Claude配置指南.md)

## 🔧 常用命令

### 服务管理
```bash
# Clash 管理
~/clash-control.sh status   # 查看状态
~/clash-control.sh start    # 启动
~/clash-control.sh stop     # 停止
~/clash-control.sh restart  # 重启
~/clash-control.sh logs     # 查看日志

# Claude Proxy 管理
pm2 start claude-proxy
pm2 stop claude-proxy
pm2 restart claude-proxy
pm2 logs claude-proxy
```

### 账号管理
```bash
# 列出账号
npm run accounts:list

# 验证账号
export HTTP_PROXY=http://127.0.0.1:8083 HTTPS_PROXY=http://127.0.0.1:8083
npm run accounts:verify

# 添加账号（需要先开SSH端口转发）
# 步骤1: 本地运行
ssh -L 51121:localhost:51121 ecs-user@YOUR_SERVER_IP

# 步骤2: 服务器运行
pm2 stop claude-proxy
export HTTP_PROXY=http://127.0.0.1:8083 HTTPS_PROXY=http://127.0.0.1:8083
npm run accounts:add
```

## 🐛 故障排查

### 问题: 账号验证失败 (fetch failed)
```bash
# 1. 检查 Clash
curl http://localhost:8084/ui/

# 2. 设置代理环境变量
export HTTP_PROXY=http://127.0.0.1:8083
export HTTPS_PROXY=http://127.0.0.1:8083

# 3. 重新验证
npm run accounts:verify
```

### 问题: 服务无响应
```bash
# 1. 检查服务状态
pm2 status

# 2. 查看错误日志
pm2 logs claude-proxy --err

# 3. 重启服务
pm2 restart claude-proxy
```

### 问题: Dashboard 无法访问
```bash
# 1. 检查 Clash 状态
sudo systemctl status mihomo

# 2. 检查端口
netstat -tuln | grep 8084

# 3. 重启 Clash
sudo systemctl restart mihomo
```

## 📝 重要提醒

### ⚠️ 添加账号前必须做的事
1. **停止 PM2 服务**: `pm2 stop claude-proxy`
2. **设置代理环境变量**:
   ```bash
   export HTTP_PROXY=http://127.0.0.1:8083
   export HTTPS_PROXY=http://127.0.0.1:8083
   ```
3. **开启 SSH 端口转发** (在本地):
   ```bash
   ssh -L 51121:localhost:51121 ecs-user@YOUR_SERVER_IP
   ```

### ✅ 服务启动后检查清单
- [ ] Clash 正在运行: `curl http://localhost:8084/ui/`
- [ ] PM2 状态正常: `pm2 status`
- [ ] 健康检查通过: `curl http://localhost:8082/health`
- [ ] 至少一个账号可用: `curl http://localhost:8082/account-limits`

## 🆘 紧急重启

如果一切都不工作了，完全重启所有服务：

```bash
ssh ecs-user@YOUR_SERVER_IP

# 停止所有服务
pm2 stop all
sudo systemctl stop mihomo

# 等待5秒
sleep 5

# 启动所有服务
sudo systemctl start mihomo
sleep 3
cd ~/antigravity-claude-proxy
pm2 start ecosystem.config.cjs

# 验证
curl http://localhost:8082/health
curl http://localhost:8082/account-limits
```

如果仍然不工作，查看日志：
```bash
pm2 logs claude-proxy --lines 50
journalctl -u mihomo -n 50
```
