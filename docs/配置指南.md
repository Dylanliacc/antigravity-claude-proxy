## 系统要求

- **Node.js** 18 或更高版本
- **sqlite3** 命令行工具（用于自动提取 Antigravity 认证信息）
- **Antigravity** 应用已安装并登录（单账户模式）

### 安装 sqlite3

```bash
# Ubuntu/Debian
sudo apt-get install -y sqlite3

# macOS
brew install sqlite3

# Arch Linux
sudo pacman -S sqlite
```

## 配置认证

### 方式一：自动提取 Antigravity 认证（推荐）

如果你已经在 Antigravity 应用中登录了 Google 账户，代理服务器会**自动**从 Antigravity 的本地数据库中提取认证信息。

**前提条件：**

1. Antigravity 应用已安装
2. 已在 Antigravity 中登录 Google 账户
3. 系统已安装 `sqlite3` 命令行工具

启动服务器时会自动检测：

```bash
npm start
```

成功时会看到类似输出：

```
[AccountManager] Loaded default account: your-email@gmail.com
[Server] Account pool initialized: 1 total, 1 available
```

### 方式二：手动添加 Google 账户（多账户负载均衡）

如果需要添加多个账户进行负载均衡：

```bash
# 添加账户（会打开浏览器进行 OAuth 认证）
npm run accounts:add

# 查看所有账户
npm run accounts:list

# 验证账户是否有效
npm run accounts:verify

# 交互式账户管理
npm run accounts
```

**注意：** 添加账户前需要先停止代理服务器。

## 启动代理服务器


服务器默认运行在 `http://localhost:8080`


## 配置 Claude Code CLI

### 方式一：配置文件（推荐）

创建或编辑 Claude Code 配置文件：

**文件位置：**

- **Linux/macOS:** `~/.claude/settings.json`
- **Windows:** `%USERPROFILE%\.claude\settings.json`

**配置内容（使用 Claude 模型）：**

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://localhost:8080",
    "ANTHROPIC_MODEL": "claude-sonnet-4-5-thinking",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-5-thinking",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-5-thinking",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-5",
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-sonnet-4-5-thinking"
  }
}
```

**配置内容（使用 Gemini 模型）：**

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://localhost:8080",
    "ANTHROPIC_MODEL": "gemini-3-pro-high",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gemini-3-pro-high",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gemini-3-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gemini-2.5-flash-lite",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gemini-3-flash"
  }
}
```

**快速配置命令：**

```bash
# 创建配置目录
mkdir -p ~/.claude

# 复制配置文件（从项目目录）
cp claude-settings.json ~/.claude/settings.json
```

### 方式二：环境变量

```bash
export ANTHROPIC_BASE_URL=http://localhost:8080
export ANTHROPIC_API_KEY=dummy
claude
```

## 故障排除

### 问题：sqlite3: not found

**原因：** 系统未安装 sqlite3 命令行工具

**解决：**

```bash
# Ubuntu/Debian
sudo apt-get install -y sqlite3

# macOS
brew install sqlite3
```

### 问题：No accounts available

**原因：** 无法从 Antigravity 提取认证信息

**解决：**

1. 确保 Antigravity 应用正在运行
2. 确保已在 Antigravity 中登录
3. 确保 sqlite3 已安装
4. 或者手动添加账户：`npm run accounts:add`

### 问题：401 Authentication Errors

**原因：** 令牌已过期

**解决：**

```bash
# 刷新令牌
curl -X POST http://localhost:8080/refresh-token

# 或重新认证
npm run accounts
```

### 问题：429 Rate Limiting

**原因：** 请求频率过高

**解决：**

- 多账户模式下会自动切换到下一个可用账户
- 单账户模式需要等待配额重置
- 检查配额状态：`curl "http://localhost:8080/account-limits?format=table"`

### 问题：Account Shows as "Invalid"

**原因：** 账户需要重新认证

**解决：**

```bash
npm run accounts
# 选择 "Re-authenticate" 重新认证
```

| 端点              | 方法 | 描述                                                |
| ----------------- | ---- | --------------------------------------------------- |
