# Antigravity Claude Proxy 项目介绍与配置指南

---

## 项目概述

### 项目名称
**Antigravity Claude Proxy**

### 版本信息
- 当前版本：v1.0.2
- 许可证：MIT
- 作者：Badri Narayanan
- 项目地址：https://github.com/badri-s2001/antigravity-claude-proxy

### 项目简介

Antigravity Claude Proxy 是一个 Node.js 代理服务器，它对外暴露 **Anthropic 兼容的 API 接口**，后端连接到 **Antigravity 的 Cloud Code 服务**。这使得用户能够通过 Claude Code CLI 工具使用多种 Claude 和 Gemini 模型。

### 核心价值

1. **API 格式转换**：将 Anthropic Messages API 格式请求转换为 Google Generative AI 格式
2. **多模型支持**：同时支持 Claude 和 Gemini 系列模型
3. **完整功能支持**：支持扩展思考（Extended Thinking）、流式输出、多轮对话
4. **多账户负载均衡**：支持添加多个 Google 账户实现自动负载均衡
5. **提示缓存**：支持 Anthropic 提示缓存以提高效率

## 工作原理

### 请求流程架构

```
┌──────────────────┐     ┌─────────────────────┐     ┌────────────────────────────┐
│   Claude Code    │────▶│  Proxy Server       │────▶│  Antigravity Cloud Code    │
│   (Anthropic     │     │  (Anthropic → Google│     │  (daily-cloudcode-pa.      │
│    API format)   │     │   Generative AI)    │     │   sandbox.googleapis.com)  │
└──────────────────┘     └─────────────────────┘     └────────────────────────────┘
```

### 详细流程

1. **接收请求**：接收来自 Claude Code CLI 的 Anthropic Messages API 格式请求
2. **认证处理**：使用配置的 Google 账户 OAuth 令牌（或从 Antigravity 本地数据库提取）
3. **格式转换**：将请求转换为 Google Generative AI 格式，并添加 Cloud Code 封装
4. **发送请求**：发送到 Antigravity 的 Cloud Code API
5. **响应转换**：将响应转换回 Anthropic 格式，完整支持思考输出和流式传输

## 技术架构

### 核心模块

| 模块 | 文件路径 | 功能描述 |
|------|----------|----------|
| Express 服务器 | `src/server.js` | 对外暴露 Anthropic 兼容端点 |
| CloudCode 客户端 | `src/cloudcode-client.js` | 与 Antigravity Cloud Code API 通信 |
| 请求转换器 | `src/format/request-converter.js` | Anthropic → Google 请求格式转换 |
| 响应转换器 | `src/format/response-converter.js` | Google → Anthropic 响应格式转换 |
| 内容转换器 | `src/format/content-converter.js` | 消息内容和角色转换 |
| Schema 清理器 | `src/format/schema-sanitizer.js` | Gemini API JSON Schema 兼容处理 |
| 思考工具 | `src/format/thinking-utils.js` | 思考块验证、过滤、重排序和恢复 |
| 签名缓存 | `src/format/signature-cache.js` | Gemini thoughtSignature 内存缓存 |
| 账户管理器 | `src/account-manager.js` | 多账户池管理、粘性选择、速率限制处理 |
| OAuth 模块 | `src/oauth.js` | Google OAuth 实现 |
| 令牌提取器 | `src/token-extractor.js` | 从本地 Antigravity 应用提取令牌 |
| 常量配置 | `src/constants.js` | API 端点、模型映射、配置值 |
| 错误处理 | `src/errors.js` | 自定义错误类 |

### 多账户负载均衡机制

- **粘性账户选择**：在对话轮次间保持使用同一账户以最大化提示缓存命中率
- **智能切换**：仅当速率限制超过 2 分钟时才切换账户
- **会话 ID**：基于首条用户消息的 SHA256 哈希生成，确保缓存连续性
- **状态持久化**：账户状态保存在 `~/.config/antigravity-proxy/accounts.json`

### 提示缓存机制

- 缓存范围：组织级别（需要相同账户 + 会话 ID）
- 会话 ID：首条用户消息内容的 SHA256 哈希值
- 缓存命中时返回 `cache_read_input_tokens`
- 令牌计算：`input_tokens = promptTokenCount - cachedContentTokenCount`

## API 端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/health` | GET | 健康检查端点 |
| `/account-limits` | GET | 账户状态和配额限制（添加 `?format=table` 获取 ASCII 表格格式） |

## 认证配置

### 方式 A：使用 Antigravity 自动提取（单账户模式）

如果你已经安装并登录了 Antigravity 应用，代理服务器会自动提取你的认证令牌。

**前提条件：**
1. Antigravity 应用已安装
2. 已在 Antigravity 中登录 Google 账户
3. 系统已安装 sqlite3 命令行工具

**认证信息存储位置：**
- **macOS**: `~/Library/Application Support/Antigravity/User/globalStorage/state.vscdb`
- **Windows**: `%APPDATA%/Antigravity/User/globalStorage/state.vscdb`
- **Linux**: `~/.config/Antigravity/User/globalStorage/state.vscdb`

**验证方式：**
```bash
# 启动服务器
npm start

# 成功时会看到类似输出：
# [AccountManager] Loaded default account: your-email@gmail.com
# [Server] Account pool initialized: 1 total, 1 available
```

### 方式 B：手动添加 Google 账户（多账户模式，推荐）

通过 OAuth 添加一个或多个 Google 账户实现负载均衡：

```bash
# npm 全局安装方式
antigravity-claude-proxy accounts add

# npx 方式
npx antigravity-claude-proxy accounts add

# 克隆仓库方式
npm run accounts:add
```

**操作流程：**
1. 执行命令后会自动打开浏览器
2. 选择 Google 账户并登录
3. 授权应用访问权限
4. 浏览器显示成功消息，关闭即可
5. 可重复操作添加多个账户

**账户管理命令：**
```bash
# 列出所有账户
antigravity-claude-proxy accounts list
# 或 npm run accounts:list

# 验证账户是否有效
antigravity-claude-proxy accounts verify
# 或 npm run accounts:verify

# 交互式账户管理
antigravity-claude-proxy accounts
# 或 npm run accounts

# 删除账户
npm run accounts:remove
```

**账户配置文件位置：**
`~/.config/antigravity-proxy/accounts.json`

## 配置 Claude Code CLI

### 方法一：配置文件方式（推荐）

**配置文件位置：**
- **Linux/macOS**: `~/.claude/settings.json`
- **Windows**: `%USERPROFILE%\.claude\settings.json`

**创建配置目录：**
```bash
mkdir -p ~/.claude
```

**Claude 模型配置示例：**

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://localhost:8080",
    "ANTHROPIC_MODEL": "claude-opus-4-5-thinking",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-5-thinking",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-5-thinking",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-5",
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-sonnet-4-5-thinking"
  }
}
```

**Gemini 模型配置示例：**

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://localhost:8080",
    "ANTHROPIC_MODEL": "gemini-3-pro-high",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gemini-3-pro-high",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gemini-3-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gemini-2.5-flash-lite",
    "CLAUDE_CODE_SUBAGENT_MODEL": "gemini-3-flash"
  }
}
```

**配置项说明：**

| 配置项 | 说明 |
|--------|------|
| `ANTHROPIC_AUTH_TOKEN` | 认证令牌，代理模式下可设为任意值 |
| `ANTHROPIC_BASE_URL` | 代理服务器地址 |
| `ANTHROPIC_MODEL` | 默认使用的模型 |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | /model opus 使用的模型 |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | /model sonnet 使用的模型 |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | /model haiku 使用的模型 |
| `CLAUDE_CODE_SUBAGENT_MODEL` | 子代理使用的模型 |

## 故障排除

### 问题：sqlite3: not found

**原因：** 系统未安装 sqlite3 命令行工具

**解决方案：**
```bash
# Ubuntu/Debian
sudo apt-get install -y sqlite3

# macOS
brew install sqlite3
```

### 问题：No accounts available

**原因：** 无法从 Antigravity 提取认证信息

**解决方案：**
1. 确保 Antigravity 应用正在运行
2. 确保已在 Antigravity 中登录
3. 确保 sqlite3 已安装
4. 或者手动添加账户：`npm run accounts:add`

### 问题：401 Authentication Errors

**原因：** OAuth 令牌已过期

**解决方案：**
```bash
# 刷新令牌
curl -X POST http://localhost:8080/refresh-token

# 或重新认证账户
npm run accounts
```

### 问题：429 Rate Limiting

**原因：** 请求频率超过配额限制

**解决方案：**
- 多账户模式下会自动切换到下一个可用账户
- 单账户模式需要等待配额重置（通常为 1 分钟）
- 查看配额状态：`curl "http://localhost:8080/account-limits?format=table"`
- 添加更多账户以分散负载：`npm run accounts:add`

### 问题：Account Shows as "Invalid"

**原因：** 账户认证已失效，需要重新认证

**解决方案：**
```bash
npm run accounts
# 选择 "Re-authenticate" 重新认证无效账户
```

### 问题：Connection Refused

**原因：** 代理服务器未运行

**解决方案：**
```bash
# 确保在另一个终端启动了服务器
npm start
```

## 快速开始流程

完整的从零开始配置流程：

```bash
# 步骤 1：安装 sqlite3（可选，用于自动提取令牌）
sudo apt-get install -y sqlite3

# 步骤 2：克隆或安装项目

mkdir -p ~/.claude

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "test",
    "ANTHROPIC_BASE_URL": "http://localhost:8080",
    "ANTHROPIC_MODEL": "claude-opus-4-5-thinking",

    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-5-thinking",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-5",
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-sonnet-4-5-thinking"
  }
}
EOF

# 步骤 6：运行 Claude Code
claude
```
